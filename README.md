## 🚀 Running Locally

No npm installs or dependencies are needed! A zero-dependency Node.js HTTP server is included:

```bash
# Start the local server
npm start
# or
node server.js
```

Open your browser at:
```
http://localhost:3000
```

## 🌐 Deploying to Production

This project can be deployed to any static host or modern cloud platform:

- **Vercel**: Deploy directly (`vercel deploy`) or push to a GitHub repository connected to Vercel.
- **Hostinger / cPanel**: Upload all files to `public_html/`.
- **Netlify**: Drag and drop the folder or push to GitHub.
- **GitHub Pages**: Push this repository to GitHub and enable Pages in repository settings.
